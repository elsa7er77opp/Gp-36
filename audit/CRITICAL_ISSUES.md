## Limitations of the leakage detection used here
* SHA-256 finds only byte-identical files, so 42 is a lower bound.
* A dHash-64 Hamming distance ≤4 has false positives: for example, `10_jpg` matched three differently named, visually similar dash-cam frames. It also misses crops, flips and re-scaled images. The 100-image figure is a screening result that still needs visual confirmation.
* No metadata (GPS, video ID) exists for the Roboflow images, so grouping by scene or location cannot be fully verified.
